# Database

Create a PostgreSQL database named `utaam_medical` before starting the backend.

The backend uses PostgreSQL on `localhost:5432`. Configure `DB_USERNAME` and `DB_PASSWORD` as environment variables when your local PostgreSQL credentials differ from the defaults in `backend/src/main/resources/application.yml`.

Sample medicine and batch data is in `../sample-data/01_sample_medicines_and_batches.sql`.
